| 图 | 首次可见后的顺序 | 目的 |

| Enforcement | Builder → 执行点 → Publish / QC | 规则进入边界，约 1 秒；不模拟实际 QC 成功 |
| Shared semantics | Reality → 六语义框架 → Execution → Maya / Houdini | 语义共享不等于文件处理器，约 1.9 秒 |

每组用 data-step 描述语义顺序，GSAP 唯一负责组透明度与连接线绘制。淡入 450ms、组间错开 300ms（生产图 380ms），power2.out。几何不因动画重新布局。正文与标题一直可读，不逐字隐藏正文。首次进入约 15% 可见区域触发，离屏或后台暂停，返回续播，完成保持；无无限 RAF。

## 交互、降级与实现

- 原生页面链接导航；仅 BACK TO TOP 使用页内锚点。
- 图形无需点击即可理解，SVG 有标题和描述，正文提供同义解释。无伪交互或不可聚焦热点。
- 桌面遵守目标比例；小屏正文与图上下排列，复杂生产图提供有标签、可键盘聚焦的局部横向阅读区，避免全页溢出。共享语义三栏在手机纵排。
- SSR 输出完整图与正文；JS 未运行、加载失败或 reduced motion 时直接显示终态。运行中开启 reduced motion 立即结束动画。
- GSAP 动态加载，动画仅在小型客户端外壳内运行；页面与图形由 Server Components 生成。不添加新动画依赖。
- 卸载清理 observer、visibility 监听与 timeline；不影响首页编辑状态或现有动效。
